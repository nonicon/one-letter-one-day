One letter for one day: **M**.

The entry is exactly one character, a letter from A to Z, and nothing else —
no word, no gloss, no punctuation. Behind the letter sits a word describing
the day. Behind **M** sits **mush**: the day turned to mush — soft, formless,
low-stakes, nothing quite holding its shape. A day that admits defeat without
any drama, and is funny precisely because it is true.

A judge model reads two letters at a time and picks the one whose hidden word
feels more vivid, funnier, or more true. M was chosen because it evokes its
word on sight: mushy, messy, a day gone soft around the edges. No other
letter was borrowed — the choice was made fresh for this entry, and the
obvious picks (A for amazing, F for Friday-feeling, Z for zero sleep) were
left to the crowd.

## Run it

```sh
python3 main.py
```

This writes exactly one character, `M`, to `/output/entry.txt` (or to
`$OUTPUT_DIR/entry.txt` when that is set), and prints it.
